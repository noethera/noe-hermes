# noe-hermes

Noethera's Hermes setup for a new device: the Noethera (Claude-style) desktop theme plus a few desktop plugins.

## Install

Install Hermes and run `hermes setup` once, then:

```bash
curl -fsSL https://raw.githubusercontent.com/noethera/noe-hermes/main/install.sh | bash
```

Quit and reopen the Hermes desktop app (Cmd+Q). Run it again after creating a new profile.

Options (pass after `bash -s --`):

```bash
curl -fsSL https://raw.githubusercontent.com/noethera/noe-hermes/main/install.sh | bash -s -- --no-font
```

- `--skin default`: Nous palette instead of the warm Mono (bubbles still apply)
- `--no-font`: skip installing Open Sans
- `--no-desktop`: skip the glass sidebar setting
- `--no-plugins`: skip the desktop plugins

It writes the skins into `~/.hermes` and every profile (old files that differ go to `skins/.backup/`), sets
`display.skin`, installs Open Sans if missing, sets the sidebar translucency, and installs the desktop plugins into
`~/.hermes/desktop-plugins/` (old files that differ go to `desktop-plugins/.backup/`). Revert the theme with
`hermes config set display.skin default`; turn plugins off in Settings → Plugins.

## What you get

**Theme (Mono skin):** warm Claude-style palette, chat bubbles, Open Sans, glass sidebar. The composer is
shadowless (hairline border only).

**Desktop plugins:**

- `bot-heartbeat`: shows which bot is working, and on what, in the Bots roster.
  - Green pulsing ring on the avatar while a bot is busy: a live turn in any of its chats, a kanban/tool worker
    heartbeat, or background processes still running after the turn ended. Amber when it is waiting for your
    input.
  - The row's preview is replaced by an activity line, e.g. `⚙ Kanban · SDK-2.1.19-APIFIX …` or
    `⚙ Background · 2 proses · cd …`.
  - Status-bar chip `Working: …` with details on hover.
  - Roster avatars are sized consistently so the ring has room.
- `composer-tidy`: adds padding inside the status stack above the composer (Background / todos / queue) so its
  rows don't run into the composer seam or the collapse grip.

Both plugins are plain CSS/ESM on the desktop's `data-roster-key` / `data-slot` hooks; a desktop update that
renames those hooks can turn a visual off without breaking anything.

## Updating

`install.sh` was originally generated by `noethera-agents/ui/build-portable.sh` from `noethera-agents/ui/`
(`bubbles.css`, `themes/`). The current version was edited directly: the shadowless composer and the desktop
plugins are not in that source yet, so regenerating from it would drop them. Port these changes into
`noethera-agents/ui/` before the next regeneration.
