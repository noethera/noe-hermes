# noe-hermes

Noethera's Hermes setup for a new device: the Noethera (Claude-style) desktop theme plus a few desktop plugins.

## Install

Install Hermes and run `hermes setup` once, then:

```bash
curl -fsSL https://raw.githubusercontent.com/noethera/noe-hermes/main/install.sh | bash
```

Quit and reopen the Hermes desktop app (Cmd+Q). Run it again after creating a new profile.

Options (pass after `bash -s --`):

```bash
curl -fsSL https://raw.githubusercontent.com/noethera/noe-hermes/main/install.sh | bash -s -- --no-font
```

- `--skin default`: Nous palette instead of the warm Mono (bubbles still apply)
- `--no-font`: skip installing Open Sans
- `--no-desktop`: skip the glass sidebar setting
- `--no-plugins`: skip the desktop plugins
- `--no-avatars`: skip the bot avatars

It writes the skins into `~/.hermes` and every profile (old files that differ go to `skins/.backup/`), sets
`display.skin`, installs Open Sans if missing, sets the sidebar translucency, and installs the desktop plugins into
`~/.hermes/desktop-plugins/` (old files that differ go to `desktop-plugins/.backup/`). Revert the theme with
`hermes config set display.skin default`; turn plugins off in Settings → Plugins. It also sets the bot avatars
(see below) in every agent profile that exists on the machine.

## What you get

**Theme (Mono skin):** warm Claude-style palette, chat bubbles, Open Sans, glass sidebar. The composer is
shadowless (hairline border only).

**Desktop plugins:**

- `bot-heartbeat`: shows which bot is working, and on what, in the Bots roster.
  - Green pulsing ring on the avatar while a bot is busy: a live turn in any of its chats, a kanban/tool worker
    heartbeat, or background processes still running after the turn ended. Amber when it is waiting for your
    input.
  - The row's preview is replaced by an activity line, e.g. `⚙ Kanban · SDK-2.1.19-APIFIX …` or
    `⚙ Background · 2 proses · cd …`.
  - Status-bar chip `Working: …` with details on hover.
  - Roster avatars are sized consistently so the ring has room.
- `composer-tidy`: adds padding inside the status stack above the composer (Background / todos / queue) so its
  rows don't run into the composer seam or the collapse grip.

Both plugins are plain CSS/ESM on the desktop's `data-roster-key` / `data-slot` hooks; a desktop update that
renames those hooks can turn a visual off without breaking anything.

**Bot avatars:** every non-Lead agent gets a petdex pet that matches its job (`avatars/pets.tsv`: profile, petdex
slug, why). Lead profiles (Arion, Auxon, Mom Club, Monne, Noethera, Ombak Surf, Qalwa) keep their logo and are not
listed. Each PNG is the pet's first sprite frame at 96×104, the same crop the Bots → Edit Profile → Pet tab saves.
The installer writes `profiles/<name>/assets/avatar.png` (a different old avatar goes to `assets/.backup/`). If
the desktop still shows an old avatar, it is the app's local cache: re-pick the pet in Edit Profile once.

To change one: pick the pet in the app, then copy `~/.hermes/profiles/<name>/assets/avatar.png` to
`avatars/<name>.png` and update its row in `pets.tsv`.

## Repo layout (single source since 2026-10-23)

This repo is the only home of the Noethera desktop theme and plugins (moved here from `noethera-agents`, which now
holds agent rules only).

- `install.sh`: one-file installer for a new device (hand-edited; see Updating).
- `ui/`: theme source: `bubbles.css`, `themes/*.yaml`, `install-skin.sh` (writes skins into ~/.hermes and every
  profile), `build-portable.sh` (regenerates `ui/dist/noethera-theme-setup.sh`).
- `plugins/`: Hermes plugins with a dashboard/Python half (`agent-activity`, `bot-heartbeat`, ...). `plugins/install.sh`
  symlinks each into ~/.hermes/plugins and every profile, so this folder is LIVE on the Mac mini: commit before
  editing, and never move it without re-pointing the links.
- `avatars/`: bot avatars (`<profile>.png`) and `pets.tsv`, installed by step 6 of `install.sh`.
- `desktop-only-plugins/`: copies of desktop-only plugins installed in ~/.hermes/desktop-plugins that had no source
  folder before (`bot-roster-dividers`, `composer-tidy`, `sidebar-click-new-tab`), plus `tab-guard` (a bot click opens
  its Bot Chat as a tab instead of overwriting the main tab; user-closed session tabs never come back on their own).
  `tab-guard`, `sidebar-click-new-tab` and `bot-heartbeat` ship in `install.sh`: after editing one, re-embed it with
  `python3 tools/embed_desktop_plugins.py <id>=<path/to/plugin.js>`. Tests: `node --test desktop-only-plugins/*/plugin.test.mjs`;
  live check: `desktop-only-plugins/tab-guard/e2e.mjs` against an isolated dev instance (CDP :9333).

## Updating

`install.sh` was originally generated by `ui/build-portable.sh` from `ui/` (`bubbles.css`, `themes/`). The current
version was edited directly: the shadowless composer and the desktop plugins are not in that source yet, so
regenerating from it would drop them. Port these changes into `ui/` before the next regeneration.
